# Katherine Dai

Personal academic website at https://kd0311.github.io, based on the [al-folio starter](https://github.com/alshedivat/al-folio) (upstream commit `8158dd0`).

Edit the About, Research, and Contact pages in `_pages/`. Site settings live in `_config.yml`. GitHub Pages uses the **GitHub Actions** publishing source and builds the site from `main`.
